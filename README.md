# JigTail

A small, free, native macOS menu-bar utility that keeps your Mac awake — a modern
replacement for [Jiggler](https://www.sticksoftware.com/software/Jiggler.html), rebuilt
from scratch in Swift/SwiftUI with a neumorphic UI drawn from the same design language as
[PawseKeys](https://pawsekeys.app).

JigTail waits until you've been idle for a while, then nudges your Mac just enough to
keep the screensaver and sleep at bay — so you don't have to babysit a long render, build,
download, or backup.

## Status

v0.1 — Phases 0-4 of the plan (`/Users/pablocampina/.claude/plans/fuzzy-puzzling-glacier.md`)
are built. Working:

- Idle-based jiggling with a configurable idle threshold and jiggle interval
- Manual on/off via the menu bar popover's big knob
- Conditional triggers (Trigger Conditions tab in Settings): jiggle only while a chosen app
  is running, CPU is busy, or Music/Spotify is playing — combined with OR logic
- Timed auto-stop ("run for N hours, then stop")
- Sleep prevention (`IOPMAssertion`) alongside the jiggle itself
- Full Settings window (General, Trigger Conditions, Timed Auto-Stop, About)
- Launch at login (`SMAppService`)
- Light/dark/system theme override
- Neumorphic SwiftUI design system ported from `neurocampx-ds`
- App icon (`JigTail/Resources/Assets.xcassets/AppIcon.appiconset`)

Not yet done (Phase 4 items that need the maintainer's own Apple Developer credentials,
which can't be fabricated here):

- Actually running `Scripts/build_release.sh` end-to-end — it's written and ready, but
  needs a real Developer ID Application certificate, a `notarytool` keychain profile, and
  your Team ID filled into `Scripts/ExportOptions.plist` (the script's header comment walks
  through the one-time setup)
- Sparkle auto-updates — not wired in yet. Needs an EdDSA keypair (generated by Sparkle's
  own tooling) and a real hosted `appcast.xml` URL before it can be added; wiring it in
  blind, without a real feed to test against, would just be code that looks done but can't
  be verified

Explicitly deferred (Phase 5, "stretch" per the plan, not part of this build): a rotary
drag-to-set-interval gesture on the Knob, screen-share-aware pause, and additional trigger
types.

## Requirements

- macOS 13 (Ventura) or later, Apple Silicon only
- Xcode 15+
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`) — the
  `.xcodeproj` is generated from `project.yml`, which is the source of truth for project
  structure

## Building

```bash
xcodegen generate
open JigTail.xcodeproj
```

Or from the command line:

```bash
xcodegen generate
xcodebuild -project JigTail.xcodeproj -scheme JigTail -configuration Debug build
xcodebuild -project JigTail.xcodeproj -scheme JigTail -configuration Debug test
```

If you change the project structure (add/remove targets, change settings), edit
`project.yml` and re-run `xcodegen generate` — don't hand-edit `JigTail.xcodeproj`.
